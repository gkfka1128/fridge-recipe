# 냉장고야 부탁해 — 레시피 웹사이트

빌드 없는 정적 사이트. `index.html` 을 브라우저로 열면 바로 동작한다.

| 파일 | 내용 |
|---|---|
| `data.js` | **레시피·재료·가격·장바구니 데이터 — 팀원은 이 파일만 고치면 됨** |
| `app.js` | 재료 선택 → 레시피 매칭, 상세 창, 장바구니 계산 |
| `index.html`, `style.css` | 화면 |

## 기능 (계획서 3-1 내용과 대응)

- **재료로 레시피 찾기** — 재료 칩을 누르면 "지금 바로 가능 / ○○ 필요" 순으로 정렬. 전자레인지만·10분 이내 필터.
- **자취생 맞춤** — 1인분, 15분 이내, 인덕션·전자레인지, 기본 양념은 있다고 가정(`PANTRY`).
- **소량 구매 연결** — 재료마다 최소 구매 단위 + 컬리/쿠팡 검색 링크.
- **남은 재료 이어 쓰기** — 레시피 상세에서 남은 재료 → 다음 레시피로 이동.
- **비용 비교** — 1인분 재료비 vs 배달가, "이번 주 장바구니"로 몇 끼 해결되는지.
- **보관 팁** — 재료별 보관법·기간.
- 레시피 바로가기 링크: `index.html#recipe=tofu-braise` (카드뉴스 QR에 사용)

## 레시피 추가 방법

`data.js` 의 `RECIPES` 배열에 아래 형식으로 추가:

```js
{
  id: "영문-아이디", name: "레시피 이름", time: 10, level: "쉬움", tool: "인덕션",
  ing: [["tofu", "1/2모", 0.5], ["egg", "1개", 0.1]],   // [재료키, 표시 양, 단위 대비 비율]
  sauce: "간장 1, 설탕 1/2 (큰술)",
  steps: ["1단계", "2단계", "3단계"],
  leftover: [["tofu", "두부 1/2모", "tofu-egg-soup"]],  // 남는 재료 → 이어서 만들 레시피 id
  delivery: { name: "비슷한 배달 메뉴", price: 10000 },
},
```

새 재료가 필요하면 `INGREDIENTS` 에 먼저 추가.
